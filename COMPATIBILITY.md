# Compatibilidad

**Español** | [English](COMPATIBILITY.en.md)

| Destino | Estado | Observaciones |
| --- | --- | --- |
| Windows `.exe` de 32 bits | Disponible | Compatible con Windows 7 SP1, 8, 8.1, 10 y 11 |
| Windows `.exe` de 64 bits | Disponible | Compatible con Windows 7 SP1, 8, 8.1, 10 y 11 |
| Android `.apk` | Disponible | Android 6.0 / API 23 o posterior |

Scrapp y las aplicaciones Windows que genera utilizan un runtime compatible con Windows 7 SP1. La exportación a Android depende del JDK y del Android SDK instalados; las versiones actuales de esas herramientas pueden no ser compatibles con Windows 7.

Los proyectos que dependan de servicios en línea, cámara, micrófono, dispositivos externos o extensiones remotas pueden requerir permisos y conectividad adicionales.
