# Compatibility

[Español](COMPATIBILITY.md) | **English**

| Target | Status | Notes |
| --- | --- | --- |
| 32-bit Windows `.exe` | Available | Compatible with Windows 7 SP1, 8, 8.1, 10, and 11 |
| 64-bit Windows `.exe` | Available | Compatible with Windows 7 SP1, 8, 8.1, 10, and 11 |
| Android `.apk` | Available | Android 6.0 / API 23 or later |

Scrapp and the Windows applications it generates use a runtime compatible with Windows 7 SP1. Android export depends on the installed JDK and Android SDK; current versions of those tools may not support Windows 7.

Projects that rely on online services, a camera, a microphone, external devices, or remote extensions may require additional permissions and connectivity.
